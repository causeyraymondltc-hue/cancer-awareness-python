# Cancer Awareness & Educational ML Toolkit

A Python web application demonstrating **health literacy** and **machine learning** 
using only public, anonymized datasets.

## ⚠️ Disclaimer
This project is for **educational and portfolio use only**. 
It is **not** a medical device or clinical diagnostic tool.

## Features
- Prevention awareness calculator with evidence-based tips.
- Interactive ML demo using the public Wisconsin Breast Cancer dataset.
- Built with Streamlit, scikit-learn, and Plotly.
